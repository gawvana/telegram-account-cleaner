Разделы CLIN

Добро пожаловать в CLIN

Перед началом использования ознакомьтесь с правилами сервиса и политикой конфиденциальности:

1. Назначение: CLIN предназначен исключительно для личной гигиены вашего собственного Telegram-аккаунта.

2. Локальное шифрование: Сессионные ключи шифруются алгоритмом Fernet (AES-128-CBC) с персональной солью. Пароли 2FA и SMS-коды никогда не сохраняются на диске.

3. Полный контроль: Никакие чаты не удаляются автоматически без вашего предварительного выбора и подтверждения. Белый список имеет абсолютный приоритет.

4. Отзыв согласия: Вы можете в любой момент отозвать согласие в Настройках — сессия будет мгновенно занулена и удалена с сервера.

Подтверждение Deep Clean

Операция Deep Clean выполнит комплексную очистку всех диалогов, кроме находящихся в Белом списке. Ссылки на каналы сохранятся в Rejoin Manifest.

Как получить API ID и API Hash

01
Откройте официальный Telegram Core:
https://my.telegram.org
02
Войдите в свой Telegram-аккаунт через номер телефона.
03
Откройте раздел: API development tools.
04
Создайте приложение (App), если его ещё нет, указав любое название.
05
Telegram сгенерирует ключи:
• App api_id (число)
• App api_hash (хэш-строка)
Важно: API Hash нельзя публиковать или отправлять другим людям. Не добавляйте его в открытый доступ.
